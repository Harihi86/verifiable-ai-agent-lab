## 3. Continuous learning / instincts pipeline

**Storage root (VIS).** `CLV2_HOMUNCULUS_DIR` (absolute) → `$XDG_DATA_HOME/ecc-homunculus` → `~/.local/share/ecc-homunculus` (`scripts/lib/observer-sessions.js:8-26`; `skills/continuous-learning-v2/scripts/lib/homunculus-dir.sh:9-31`). Layout: `projects.json` registry, `projects/<id>/{project.json, observations.jsonl, observations.archive/, instincts/{personal,inherited,pending}, evolved/{skills,commands,agents}, .observer.pid, .observer-sessions/, .observer-tmp/}`, plus the same tree at the root for "global" (`detect-project.sh:24-26,235-243,276`; `SKILL.md:259-285`). Moved out of `~/.claude` so Claude Code's sensitive-path guard does not block background writes (DOC `SKILL.md:138-150`; `migrate-homunculus.sh:6-10`).

**Project identity (VIS).** `CLAUDE_PROJECT_DIR` → `git remote get-url origin` (credentials stripped, normalized, lower-cased for network remotes) → `git rev-parse --show-toplevel`; ID = first 12 hex of SHA-256 (`observer-sessions.js:54-92`; `detect-project.sh:108-232`).

**Observation pipeline (VIS).**
1. Hooks #5 (PreToolUse `pre:observe`, async) and #16 (PostToolUse async `post:observe:continuous-learning`) call `observe-runner.js`, which locates a bash (`resolveWindowsBashCandidates` excludes WSL launchers) and runs `observe.sh pre|post` with the raw payload on stdin and a 9 s timeout (`observe-runner.js:9-10,48-76,131-142`; `scripts/lib/windows-bash.js:43-80`).
2. `observe.sh` exits early for: no Python, `CONFIG_DIR/disabled`, non-interactive entrypoints, `ECC_HOOK_PROFILE=minimal`, `ECC_SKIP_OBSERVE=1`, subagent payloads (`agent_id`), and cwd matching `ECC_OBSERVE_SKIP_PATHS` (`observe.sh:69-92,139-182`).
3. It records `{timestamp, event: tool_start|tool_complete, tool, session, project_id, project_name, input|output}` where input/output is `json.dumps(tool_input)[:5000]` / `tool_response[:5000]`, passed through a linear-time regex that redacts `(api_key|token|secret|password|authorization|credentials|auth)` followed by a value of 8-256 chars (`observe.sh:213-262,317-364`). On parse failure it appends the raw payload (first 2000 chars, same scrub) (`:266-295`). File rotates at 10 MB into `observations.archive/`; archives older than 30 days are deleted daily (`:201-209,300-305`).
4. Every ~20 observations it `kill -USR1`s a running observer; it lazy-starts the observer only when `observer.enabled` is true (`:366-388,494-502,569-693`).

**Privacy implication (VIS+INF).** Observations contain tool inputs and outputs (file contents returned by Read, command output, edit strings) up to 5 KB each, plaintext on disk, scrubbed only by a keyword-adjacent regex. Prompt text is *not* captured by these hooks (no UserPromptSubmit observer), contrary to the SKILL diagram "prompts, tool calls, outcomes" (DOC `SKILL.md:84-92`). Session summaries (Section 4) do store user prompt excerpts.

**Observer agent (VIS).** `start-observer.sh` launches `observer-loop.sh` with `nohup … &` (`start-observer.sh:209-223`). The loop: prunes pending instincts via `instinct-cli.py prune`, sleeps `OBSERVER_INTERVAL_SECONDS`, and on signal/interval runs `session-guardian.sh` gates (active hours 08:00-23:00, per-project 300 s cooldown log at `~/.claude/observer-last-run.log`, idle detection via `ioreg`/`xprintidle`/`powershell.exe`) then **spawns `claude --model haiku --max-turns N --print --allowedTools "Read,Write" -p "<prompt>"`** over the last 500 observation lines with a 120 s watchdog (`observer-loop.sh:221-242,331,400-423,515-532`; `session-guardian.sh:18-150`). The prompt tells the model it "MUST use the Write tool directly… Do NOT ask for permission" and to write `${INSTINCTS_DIR}/<id>.md` for patterns seen 3+ times; it includes an untrusted-data clause and a required `{"status":"analysis_complete"}` completion record, after which observations are archived (`observer-loop.sh:269-316,448-470`). Windows: skipped unless `ECC_OBSERVER_ALLOW_WINDOWS=true` (`:211-212`) and documented as killed with the hook's Job Object on native Windows (DOC `SKILL.md:241-251`).

**Instinct data model (VIS).** YAML-frontmatter blocks (multiple per file, `---` delimited) with `id`, `trigger`, `confidence` (float 0-1; default 0.5 on malformed), `domain`, `source`, `scope`, `project_id`, `project_name`, then Markdown body with `## Action` and `## Evidence` (`session-start.js:371-418`; `instinct-cli.py:516-570`; example `SKILL.md:52-72`; curated repo set `.claude/homunculus/instincts/inherited/ecc-instincts.yaml:4-23`). Confidence semantics (0.3 tentative → 0.9 core; +0.05/confirmation, −0.1/contradiction, −0.02/week decay) are **prompt/doc guidance to the Haiku agent, not code** (DOC `SKILL.md:323-342`, `agents/observer.md:128-139`). **Promotion / evolution (VIS).** `instinct-cli.py promote` moves project instincts to global when the same `id` appears in ≥2 projects with avg confidence ≥ 0.8 (`:129,1456-1489,1592-1601,1675`). `evolve` clusters by trigger-keyword overlap; `--generate` writes `evolved/skills/<slug>/SKILL.md`, `evolved/commands/<slug>.md` (workflow domain, conf ≥0.7), `evolved/agents/<slug>.md` (clusters ≥3, avg ≥0.75, `model: sonnet`, `tools: Read, Grep, Glob`) (`:1306-1420,1956-2060`). `import` accepts a path or **https URL** (scheme/hostname/public-IP checks, 2 MiB, 15 s) (`:189-236,887-1054`). Pending instincts auto-delete after 30 days (`:133,2158`).

**How learned content enters execution (VIS).**
- SessionStart reads `instincts/{personal,inherited}` from the global dir and the project dir, keeps `confidence ≥ ECC_INSTINCT_CONFIDENCE_THRESHOLD` (0.7), adds +0.25 for project scope and +0.2 for stack-keyword match, and injects the top `ECC_MAX_INJECTED_INSTINCTS` (6) first `## Action` lines as `Active instincts:` context (`session-start.js:38-39,135-171,458-533`; `instinct-relevance.js:27-28,149-162`). This is advisory context, not a hook or permission.
- Learned skills under `~/.claude/skills/learned/` get 6 × 220-char summaries injected (`session-start.js:40-41,575-646`); because they live under `~/.claude/skills`, Claude Code also discovers them as real skills (INF from Claude Code skill discovery; ECC's `/learn` targets `~/.claude/skills/<pattern-name>/SKILL.md` with prose-only guards: `commands/learn.md:40-53`).
- `evolved/` outputs are *not* under any auto-discovered path; a human must copy them (INF; no code copies them).
- Hookify rules (`.claude/hookify.*.local.md`) written by `/hookify` from "conversation analysis" are enforced by hook #10/#11/#15/#19 with `block` capability; git-tracked rule files are ignored unless `ECC_HOOKIFY_ALLOW_TRACKED=1` (`hookify-runtime.js:300-312,363-378`).
